# REP / RGON 静态 API 文档站设计

## 目标

将 `3113y/isaac-llm-wiki`（后续改名为 `3113y/isaac-api-wiki`）建设为面向人类开发者的 GitHub Pages 静态 API 文档站。站点必须展示实际 API 文档内容，并支持 REP、REP+、RGON 与 RGON+ 的兼容性识别及中英文阅读。

`3113y/isaac-wiki-mcp` 是唯一的内容与版本事实来源，并继续仅面向 LLM 发布 MCP 工具与结构化知识库。人类站点不承载 MCP 服务、模型逻辑或手工维护的 API 正文。

本期不处理 AB+。`ALL DLCs` 表示条目同时兼容 REP 与 REP+，且不依赖 RGON 或 RGON+。

## 仓库职责与发布边界

```text
上游 API 文档与扩展文档
        ↓
isaac-wiki-mcp：导入、规范化、验证、导出
        ↓
GitHub Actions：已验证的站点发布包
        ↓
isaac-api-wiki：MkDocs 静态站构建与 GitHub Pages 部署
```

`isaac-wiki-mcp` 维护规范化条目。每个类、枚举、方法或字段的变体包含：

- 稳定 ID、种类、所属页面、签名、参数和返回值；
- 上游英文原文及其来源；
- 中文译文；
- `rep` 或 `rep+` 基础版本，以及可选 `rgon` 或 `rgon+` 依赖；
- 与基础 API 的扩展或覆盖关系；
- 描述来源状态：`upstream`、`translated` 或 `inferred`。

英文页面总是优先展示上游英文原文。没有英文原文时，生成器只能根据签名、参数、所属类型和相邻 API 生成中英文说明；页面必须清楚标注为 LLM 推断。推断不得修改签名、参数、返回值或版本事实。

站点仓库只接收导出的 Markdown、页面映射、兼容性清单、MkDocs 配置、主题覆盖、前端样式与脚本。API 正文不在该仓库中手工编辑。

## 环境模型

环境先选择基础版本，再选择扩展：

1. 基础版本为 `REP` 或 `REP+`。
2. 当基础版本为 `REP` 时，可选扩展为“原版”或 `RGON`。
3. 当基础版本为 `REP+` 时，可选扩展为“原版”或 `RGON+`。
4. `RGON` 只能依赖 `REP`；`RGON+` 只能依赖 `REP+`。违规组合不得生成或在前端启用。
5. `ALL DLCs` 仅代表基础 API 同时支持 REP 与 REP+，无扩展依赖。

RGON 或 RGON+ 的同名 API 只有在来源明确证明其替换基础 API 时才能标为覆盖。覆盖条目必须显示其基础条目链接和“覆盖基础 API”提示；同名不能作为推断覆盖关系的依据。

## 站点界面

站点采用与 IsaacDocs 相近的 Material 文档布局：顶栏、搜索、左侧 API 分类树、中间正文与右侧页内目录。页面将使用自有 MkDocs 主题覆盖，不复制参考站代码。

顶栏包含两个环境控件：

- 基础版本的分段胶囊：`REP` / `REP+`。
- 扩展版本的滑动胶囊：`原版` / `RGON`；选定 `REP+` 后标签自动变为 `原版` / `RGON+`。

页面及目录中的条目显示紧凑版本徽章：`ALL DLCs`、`REP`、`REP+`、`RGON`、`RGON+`。当前环境不可用的条目保留可见，但在目录和正文中置灰，显示所需版本或扩展，不得被暗示为可直接使用。

语言控件为左右滑动的胶囊开关，标记为 `中文` 与 `EN`。切换必须前往当前 API 页面的语言对应页，并保留锚点、环境选择和目录位置。环境选择同时存入 URL 参数和浏览器本地存储，以便链接分享及后续浏览保持一致。

## 导出、构建与失败处理

MCP 仓库的导出器从规范化目录生成：

- 成对的 `/zh/...` 与 `/en/...` Markdown 页面；
- 每页语言映射和锚点映射；
- 条目与目录使用的兼容性数据；
- 可追溯的发布清单，包含来源版本及生成时间。

GitHub Actions 在内容或主题更新后先运行导入、目录、导出和站点契约测试。所有检查通过后才向 `isaac-api-wiki` 同步生成的站点发布包。站点仓库接收变更后以 MkDocs 严格模式构建并部署 GitHub Pages。

任一检查、同步或构建失败时，工作流不部署新站点，因此 GitHub Pages 保留最后一个成功版本。不得发布空站点或仅含导航而无 API 正文的产物。

## 验证

自动化验证至少包括：

- 每个发布页面具有实际 API 正文、签名和来源；
- 中英文页面配对，语言开关目标存在并保留环境与锚点；
- 英文原文优先；没有原文的内容带有中英文推断标识；
- `ALL DLCs`、REP/RGON、REP+/RGON+ 的徽章与环境规则正确；
- RGON/RGON+ 覆盖仅在显式来源关系存在时出现；
- 非兼容条目显示为不可用而不是消失；
- HTML 契约包含顶栏环境控件、版本徽章及语言胶囊；
- MkDocs 严格构建成功，内部页面、语言页和来源链接有效。
